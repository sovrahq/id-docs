**mDoc** es el formato del estándar internacional **ISO 18013-5**, el de la licencia de
conducir móvil (mDL). Como SD-JWT VC, vive en la wallet del ciudadano y permite mostrar
solo los datos necesarios, pero está pensado para que lo acepten verificadores de
cualquier país o sistema que siga el estándar.

Usalo cuando necesites esa interoperabilidad: licencias de conducir o documentos de
identidad oficiales. Hay dos variantes:

- **Namespace ISO:** usa exactamente los campos que define el estándar (los de una
  licencia de conducir). Es la opción para una mDL oficial.
- **Namespace propio:** mismo formato, pero con los campos que tu institución necesite
  (por ejemplo, CURP o tipo de sangre).
