Verificar un **mDoc** funciona igual que con SD-JWT VC: pedís ciertos datos, la persona
escanea un QR, elige compartir y te llega el resultado validado. Cambia cómo se escribe el
pedido, porque los datos de un mDoc se organizan por *namespace*.
