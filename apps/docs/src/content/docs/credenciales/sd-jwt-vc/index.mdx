**SD-JWT VC** es el formato de credencial por defecto de Sovra. Es un documento firmado,
basado en JSON, que vive en la wallet del ciudadano y le permite mostrar **solo los datos
que hacen falta**: por ejemplo, que es mayor de edad, sin revelar su fecha de nacimiento.

Sirve para casi todo: licencias, credenciales de identidad, membresías, títulos o
certificados de cursos. Si no tenés un motivo para elegir mDoc, usá este.

Emitir una credencial SD-JWT VC lleva dos pasos:
